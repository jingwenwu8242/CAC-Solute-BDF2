# Minimal 2D CAC--solute reference code

This directory contains a compact reference implementation of the **two-dimensional, periodic, no-flow CAC--solute subsystem** used in the CPC manuscript.

It is deliberately not a reproduction package for the complete paper. In particular, it does **not** contain the Navier--Stokes equations, velocity, pressure projection, hydrodynamic coupling, gravity, wall boundary conditions, the original multigrid implementation, or the three-dimensional examples. Consequently, it cannot reproduce the fluid-coupled numerical experiments in the paper.

No open-source license has been selected or included. A license must be chosen by
the authors before public release.

## Files

- `main.c`: complete C11 implementation, including the solver and diagnostics.
- `README.md`: model scope, numerical format, build instructions, and validation results.
- `.gitignore`: excludes compiler products and locally regenerated output directories.
- `validation/`: outputs from the verification runs reported below.

Compiler products are not part of the release candidate. The included validation
files are retained because they permit both scalar-diagnostic and final-field
comparisons; all of them can also be regenerated by the commands below.

## Implemented subsystem

With the velocity set to zero, the program advances

\[
\phi_t=-\frac{1}{Pe_\phi}\mu_\phi,
\qquad
\mu_\phi=G_1(\phi,c)-\Delta\phi,
\]

and

\[
c_t=-\frac{1}{Pe_c}D(\phi)\mu_c,
\qquad
\mu_c=G_2(\phi,c),
\]

where

\[
G_1=g_1-\frac{1}{|\Omega|}\int_\Omega g_1\,dx,
\qquad
G_2=g_2-\frac{\int_\Omega Dg_2\,dx}{\int_\Omega D\,dx}.
\]

The discrete implementation contains:

- backward Euler at the first step;
- BDF2 and the extrapolation \(f^*=2f^n-f^{n-1}\) afterward;
- Scheme B for the solute chemical potential,
  \[
  \mu_c^{n+1}=Q^{n+1}G_2(\phi^*,c^*)
  +\frac{S_c}{D(\phi^*)}(c^{n+1}-c^*);
  \]
- the E-SAV update for \(\widehat V\), \(\xi\), and \(Q\);
- the energy-optimized correction
  \[
  V^{n+1}=\min\{V^n,\exp(E^{n+1}/C)\};
  \]
- second-order cell-centered finite differences with periodic boundaries;
- a matrix-free conjugate-gradient solver for the periodic phase Helmholtz equation.

The program uses `double` precision. It evaluates every logarithm from the actual concentration and stops if `c`, `c*`, or `D(phi*)` is nonpositive. It does not use concentration clipping, mass projection, or a posteriori mass correction.

### Why the solute update is pointwise

There is no advection in this reference subsystem. Substituting Scheme B into the solute evolution equation gives

\[
\delta_t c^{n+1}
=-\frac{Q^{n+1}}{Pe_c}D(\phi^*)G_2(\phi^*,c^*)
-\frac{S_c}{Pe_c}(c^{n+1}-c^*).
\]

Thus the factors `D(phi*)` and `1/D(phi*)` cancel only in the stabilization contribution. The physical `D(phi*) G2` term remains. No solute elliptic solver is required for this no-flow Scheme-B subproblem.

## Default example

The default run uses the effective ex2 parameter group:

- domain: `[0,2] x [0,2]`;
- grid: `256 x 256`, so `h=1/128`;
- `epsilon=0.018`;
- `dt=0.01`, 160 steps;
- `Sphi=6`, `Sc=6`;
- `Pe_phi=1/epsilon`, `Pe_c=0.02`;
- `alpha1=alpha2=1`;
- `beta1=ln(0.4)`, `beta2=ln(0.8)`;
- two-droplet initial phase field and `c(x,y,0)=0.2`.

Here `Sphi` is the dimensionless number appearing in the manuscript coefficient `Sphi/epsilon^2`; the code does not divide an already scaled value by `epsilon^2` a second time.

Two cases are available:

- `--case equal`: `D1=D2=1`;
- `--case variable`: `D1=1`, `D2=0.5`.

## Compilation

### MSVC Developer Command Prompt

```bat
cl /std:c11 /O2 /W4 /D_CRT_SECURE_NO_WARNINGS main.c /Fe:cac2d_reference.exe
```

### GCC or Clang

```bash
cc -std=c11 -O2 -Wall -Wextra -pedantic main.c -lm -o cac2d_reference
```

The MSVC command was verified on Windows as described below. The source uses only
standard C11 library facilities apart from small platform-specific directory
creation wrappers. The GCC/Clang command is provided for Linux and other POSIX
systems, but it was not executed on the present Windows-only validation host.

## Running

The commands below use POSIX executable syntax. In Windows Command Prompt or
PowerShell, replace `./cac2d_reference` with `cac2d_reference.exe` or
`.\cac2d_reference.exe`, respectively.

Equal coefficients:

```bash
./cac2d_reference --case equal --output validation/equal_D
```

Variable coefficients:

```bash
./cac2d_reference --case variable --output validation/variable_D
```

Built-in temporal convergence test:

```bash
./cac2d_reference --convergence --output validation/time_convergence
```

Optional flags are `--nx N`, `--dt DT`, `--steps N`, `--output DIR`, `--no-fields`, and `--quiet`. Use `--help` for a short synopsis.

Each physical run writes:

- `diagnostics.csv`: stepwise mass errors, positivity values, energies, `Q`, residuals, CG iterations, and nonlocal zero-mean errors;
- `summary.txt`: extrema over the complete run;
- `final_fields.csv`: final `x,y,phi,c` values unless `--no-fields` is used.

## Interpretation limits

- The corrected energy `C log(V)` is nonincreasing by construction; this statement must not be replaced by an unconditional monotonicity claim for the original energy.
- Successful execution is not used as evidence of positivity. The reported minima are computed from every time step.
- The mass errors are numerical diagnostics from this independent no-flow reference implementation, not a validation of the paper's full Navier--Stokes-coupled code.
- The program is intended for method inspection and small reproducible tests, not for reproducing all figures in the manuscript.
